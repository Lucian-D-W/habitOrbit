# 星以为常 habitOrbit 使用说明

Windows x64，Windows 10 2004或更新版本。运行habitOrbit-Setup-x64.exe，默认仅为当前用户安装到LocalAppData/Programs/Pulse；开始菜单入口为星以为常 habitOrbit。沿用原Pulse安装目录与数据，原用户无需迁移。无需MindFloward、Node、Rust或.NET SDK。完整Host携带.NET与Windows App SDK依赖；安装包携带离线WebView2、VC++运行库，缺VC++时微软安装器可能要求管理员权限。安装后程序以普通权限运行。

打开星以为常 habitOrbit，创建星球；选名称、单位、每次申报的量和外观。新建默认隐藏，双击总览卡片切换桌面显隐，单击只选中，Enter查看详情。桌面中心左键一份、右键撤销今天最新一份、拖动仅移动。时长以分钟手动申报，不自动计时。点击外围应穿透到下面程序。

关闭管理窗口后Host继续运行。星以为常 habitOrbit托盘可打开管理端、临时隐藏全部或完全退出；完全退出同步关闭管理窗口、星球与托盘，未保存编辑先确认，取消保持运行。退出后重启恢复记录、外观、布局。开机启动默认关闭，可在设置中明确启用。

详情显示年度热力、最近7/30/90天柱图和选日明细；记录矩阵按日期并排显示多个活动，也包含隐藏的星球。单位和每次记录量在创建后固定；热力图分界只改变颜色解释。未来和创建前空日期不适用，有数据的日期仍可查看。归档保留历史。

设置与备份→导出备份，选择.pulse-backup文件；在线备份包含已提交事件、本机布局和版本，不依赖单独复制WAL主文件。恢复需选择备份并确认：当前数据被替换，不合并；恢复前副本保存到数据目录backups下，界面返回具体路径。失败回滚保留原库和失败文件；中断恢复在下次启动时依据维护日志回滚。开机启动保留本机选择，不从备份启用。

默认数据目录LocalAppData/Pulse，设置页显示实际物理路径，两进程使用同一路径且明确拒绝MSIX虚拟化。程序在LocalAppData/Programs/Pulse，与数据分开；卸载保留用户资料。头像缓存可删除后重建，Activity和Event不能随缓存清理。不要手工覆盖正在使用的数据库。

首次使用时，可以创建一颗演示星球，确认左键增加、右键撤销及关闭管理窗口后的托盘行为。备份恢复会替换当前资料，请勿为了试用而恢复到正在使用的真实资料上。开发构建与隔离测试入口见[开发说明](development.md)。
